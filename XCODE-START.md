# Открыть игру в Xcode

Изменён только вход и оболочка игры: удалены нарисованный телефон, его часы,
экран блокировки и рабочий стол. После входа игра занимает весь экран с отступами
для выреза и системного жеста. Существующий аккаунт сразу открывает игру.
Пять колонок, оформление карточек и правила ставок сохранены.

## На Mac

Нужны Xcode, Node.js и CocoaPods. В Xcode → Settings → Locations выбери
установленный Xcode в поле Command Line Tools.

1. Открой `Open-Xcode.command` двойным щелчком. Или в Terminal, из папки проекта:
   `bash ios/setup-ios.sh`.
2. В открывшемся Xcode выбери симулятор iPhone и нажми ▶ Run. Для установки на
   свой iPhone выбери свою Team в Signing & Capabilities и подключи устройство.

Скрипт устанавливает версии из package-lock.json, копирует актуальную игру,
синхронизирует Capacitor и CocoaPods и открывает
`ios/ios/App/App.xcworkspace`. Не открывай `.xcodeproj` вместо workspace.

## Состояние сборки

Нативный проект создан через Capacitor 5 из существующих зависимостей проекта.
Веб-файл подготовлен и скопирован в iOS-проект. Компиляция Xcode, запуск
симулятора и подписание на Linux не выполнялись. Готового IPA в комплекте нет.
Иконка и splash — стандартные ресурсы Capacitor; публикация в App Store не выполнялась.

## Изменения игры в дальнейшем

Редактируй `auction-game.html` в корне. Из папки `ios` запускай `npm run sync`.
`www` и нативная папка `public` генерируются автоматически.
